# Coordinator decisions — round 3

- **SEC-13 берётся, хотя ревью дало `approved`.** Minor не держит мёрж, но находка опровергает вывод diff review раунда 2 (координатор назвал совпадение бэкапов недостижимым, проверив одну попытку, а не цикл) и при срабатывании теряет креды с ложным «прежний файл сохранён». Исправление локальное.
- **Бэкап из прочитанных байтов, а не повторным чтением.** Повторное чтение в `backupFile` — та же гонка, которую раунд 2 сужал: между разбором и копией файл может измениться.
- **Суффикс `-N` вместо наносекунд в имени.** `revert` сортирует по mtime и ищет по префиксу; суффикс сохраняет человекочитаемое имя и формат `merge`.
